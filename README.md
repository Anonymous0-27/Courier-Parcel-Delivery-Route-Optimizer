# Courier-Parcel-Delivery-Route-Optimizer
Courier &amp; Parcel Delivery Route Optimizer is a C++ and DSA project for managing parcels and finding efficient delivery routes. It uses weighted graphs and Dijkstra’s algorithm to calculate the shortest path. Queues, searching, sorting, and file handling support parcel management and delivery planning through a simple menu-driven interface.
Our project is a C++ based courier delivery system that helps manage parcels and plan efficient delivery routes. Instead of finding only one shortest path, the system will handle several parcels, different vehicles and delivery priorities. The road network will be stored as a weighted graph. Dijkstra algorithm will find the shortest path between locations. A priority queue will help handle urgent parcels first. For multiple deliveries, the Clarke-Wright Savings Algorithm will create an initial set of routes, while 2-Opt will be used to improve those routes. Vehicle capacity will also be checked before a route is finalized. The aim is to build a practical project that combines Data Structures, algorithms and C++ OOP concepts in one system.
We will build the project as a menu-driven C++ application using classes such as Parcel, Vehicle, Location, Graph and Route Optimizer. The road network will be represented as a weighted graph. Parcels will contain details such as ID, destination, weight and priority. A priority queue will manage urgent deliveries. Dijkstra algorithm will calculate shortest road paths. The Clarke-Wright Savings Algorithm will combine delivery points into practical vehicle routes while checking vehicle capacity. The 2-Opt method will then check whether a generated route can be shortened. We will use the C++ Standard Template Library for vectors, queues and priority queues, along with basic file handling for saving project data. Each module will be tested separately before the complete system is integrated.
